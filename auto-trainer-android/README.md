# Auto Trainer APK

Это отдельное Android-приложение. Оно НЕ содержит симулятор и НЕ меняет основной проект Testung.

Архитектура:
1. Пользователь запускает Auto Trainer.
2. В системных настройках вручную включает Accessibility Service.
3. Сервис работает только когда на переднем плане пакет Testung: com.example.komandir.
4. Сервис читает доступный UI-текст, определяет известные состояния успеха/ошибки и нажимает кнопки следующего эпизода.
5. После 10 успешных эпизодов подряд экспортируется JSON-профиль навыка в Download/AutoTrainer.

Важно: Accessibility Service не видит внутреннее состояние 3D-физики само по себе. Поэтому текущая версия использует только доступные UI-тексты/описания. Для надёжного определения падения по картинке следующим этапом нужен отдельный экранный анализ через разрешённый пользователем MediaProjection или явные accessibility-состояния в Testung. Основная ветка не изменяется.
