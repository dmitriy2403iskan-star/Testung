# Как получить походку от ИИ (ChatGPT и др.) и вставить в игру

Нейросеть человека (2781 вес) руками или чужим ИИ не пишется: это числа без смысла.
Зато можно попросить ИИ написать **походку** — читаемый файл: для каждого сустава
«колебание по синусу». Игра проигрывает его как цель для суставов, а нейросеть
(по желанию, параметр `mix`) дообучается поверх.

## Как пользоваться
1. Скопируй ИИ текст из раздела «Промпт» ниже, получи JSON.
2. В игре: **Импорт** → вставь JSON → **Загрузить**. Игра включит походку, цель «ИДТИ» и подвес «Средний».
3. Смотри: идёт — хорошо; нет — вернись к ИИ с описанием («падает назад», «не двигается вперёд»).
4. Кнопка «Походка ✓/✗» включает и выключает её. Она сохраняется между запусками.

## Что реально получится
- Пример `example_gait.json` проверен в Godot: с подвесом «Средний/Сильный» человек идёт вперёд
  примерно 0.3–0.5 м/с; **без подвеса не идёт** (стоит на месте) — нужен баланс, который даёт обучение.
- Поэтому план: походка + подвес → «Авто» постепенно ослабляет подвес, пока нейросеть учится держать баланс сама.

## Формат
```json
{"gait": {"name": "имя", "period": 0.6, "mix": 0.0,
  "joints": {"thigh_l.x": {"offset_deg": -20, "amp_deg": 50, "phase": 0.0}}}}
```
- `period` — секунд на один шаг-цикл (0.2–5).
- `mix` — 0 = чистая походка; 0.25 = нейросеть добавляет до 25% диапазона сустава.
- у сустава: `offset_deg` — средний угол, `amp_deg` — размах, `phase` — сдвиг в долях цикла (0–1).
  Угол = offset + amp·sin(2π·(t/period + phase)). Итог ограничивается пределами сустава.

## Суставы (имя.ось: пределы в градусах). Нули = исходная поза (стоя, руки вдоль тела)
Корпус: spine_01.x[-20..29] spine_01.y[-20..20] spine_01.z[-14..14] spine_02.x[-14..20] spine_02.z[-10..10] spine_03.x[-14..20] spine_03.z[-10..10]
Шея/голова: neck_01.x[-29..40] neck_01.z[-29..29] head.x[-35..40] head.y[-59..59] head.z[-29..29]
Левая рука: clavicle_l.y/z[-14..14] upperarm_l.x[-170..59] upperarm_l.y[-80..80] upperarm_l.z[-40..130] lowerarm_l.x[-130..10] lowerarm_l.y[-70..70] hand_l.x[-50..50] hand_l.z[-25..25]
Правая рука: то же с _r (upperarm_r.z[-130..40])
Левая нога: thigh_l.x[-110..29] thigh_l.y[-35..35] thigh_l.z[-25..45] calf_l.x[-3..135] foot_l.x[-25..45] foot_l.z[-14..14] ball_l.x[-50..10]
Правая нога: то же с _r (thigh_r.z[-45..25])
Направление «вперёд» — +Z. По опыту: `thigh.x` отрицательный = нога вперёд, `calf.x` положительный = колено согнуто.
Для руки: upperarm_l.x и upperarm_r.x в противофазе к ногам делают естественный мах.

## Промпт для ИИ
> Ты пишешь походку для физического гуманоида. Верни ТОЛЬКО JSON в формате ниже, без пояснений.
> Человек идёт вдоль +Z. Угол сустава = offset_deg + amp_deg·sin(2π(t/period + phase)), phase в долях цикла.
> Используй только эти суставы: [вставь список суставов выше]. Не выходи за пределы углов.
> Нужно: ходьба вперёд, левая и правая нога в противофазе (phase 0 и 0.5), колено сгибается при переносе ноги,
> лёгкий наклон корпуса вперёд (spine_01.x offset ~8), руки машут в противофазе с ногами.
> Формат: {"gait": {"name": "...", "period": 0.6, "mix": 0.0, "joints": {"thigh_l.x": {"offset_deg": 0, "amp_deg": 0, "phase": 0}}}}
> Моя обратная связь после теста: <опиши, что произошло>.

## Стойка (поза без движения)
Если у всех суставов `amp_deg` = 0, файл считается позой: игра ставит цель «СТОЯТЬ» и держит эти углы.
