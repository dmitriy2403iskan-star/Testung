# Как читать лог обучения (для ChatGPT)

Проект: человек-ragdoll в Godot учится стоять, потом ходить. Метод: 8 «людей» (островов), у каждого свой sep-CMA-ES
(эволюционный поиск) над весами маленькой нейросети, которая подправляет заданную позу/походку.
У каждого свой подход: своя доля нейросети поверх позы (mix), свой стартовый шаг поиска, свой старт.
Раз в 10 поколений обмен опытом: двое худших пересаживаются к лучшему, остальные подтягиваются к нему на 10%.

Раз в минуту печатается:

    Идёт 42 мин из 720
    Задача 1 из 2: stand, подвес 1
    №1: T=2520s stand eps=118 best=7.31 sup=1 sigma=0.142 ok=88 mastered=0 (доля сети 0.30)
    ... (до №8)

- `Идёт N мин из M` - сколько минут идёт обучение (суммарно, с перезапусками) и потолок времени.
- `Задача N из 2` - задачи идут по очереди: stand (стойка), затем walk (ходьба). `подвес` - текущая ступень страховки.
- `№1..№8` - восемь людей (подходов). Все учатся одной задаче.
- `T` - секунд обучения. `eps` - номер поколения (в каждом поколении у каждого человека 16 проверенных вариантов).
- `best` - лучшая оценка этого человека в последнем поколении (больше = лучше). Для стойки при sup=3 около 7.5 - это легко
  (держит подвес); важны значения при sup=0.
- `sup` - подвес (страховочная подвязка): 3 сильный, 2, 1 слабый, 0 = без подвеса (настоящая стойка).
  Снижается, когда хотя бы 4 из 8 людей прошли ступень (75% их лучших вариантов справились 3 поколения подряд).
- `sigma` - размер шага поиска у этого человека. Если упал до ~0.003, его поиск застрял.
- `ok` - % из 8 лучших вариантов этого человека, что справились: не упали, корпус вертикален, высота >80% нормы;
  для ходьбы ещё прошли больше 1 м.
- `mastered` - сколько поколений подряд средняя модель этого человека стоит при sup=0. Нужно 10 хотя бы у одного -
  задача освоена и начинается следующая (все стартуют от лучшего).
- `доля сети` - mix: насколько нейросеть меняет позу (0.15 почти чистая поза, 0.5 сеть сильно вмешивается).

Служебные строки: `Обмен опытом: №N лучший; №A и №B перешли к нему`, `>>> Подвес снижен до N`,
`>>> Задача «...» освоена без подвеса. Идём дальше.`

Признаки проблем: sup не снижается долго при ok < 75; sigma у минимума у всех; best не растёт часами;
ходьба с большим best при малом пройденном расстоянии (возможна «хитрость» с подвесом).
